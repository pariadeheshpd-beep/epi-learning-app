# آموزش تعاملی اپیدمیولوژی

طراحی و تولید محتوا: دکتر پریا دهش — گروه اپیدمیولوژی، دانشکده بهداشت، دانشگاه علوم پزشکی کرمان

ماژول‌های تعاملی: بایاس، مخدوش‌کنندگی، اینتراکشن، اندازه‌های ارتباط (RR/OR/RD)، انواع مطالعات، بررسی طغیان، آزمون‌های آماری، و تعیین حجم نمونه و توان آزمون.

## اجرا
```
npm install
npm run dev
```
